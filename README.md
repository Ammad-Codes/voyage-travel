# VOYAGE

**Travel slowly. Arrive changed.**

A premium luxury travel agency portfolio site built with plain HTML, CSS and JavaScript. No frameworks, no build step.

## Features
- Opening preloader and curtain reveal, scroll progress bar, glass header that hides and shows on scroll
- Hero with Ken Burns zoom, split-line headline and typewriter destination names
- Filterable destination cards with 3D tilt, skeleton image loading and magnetic ripple buttons
- Sticky storytelling section with a changing image, animated counters, marquee and a drawing timeline
- Grayscale gallery with colour and caption on hover
- Booking form with validation, loading spinner and an animated confirmation
- Mobile slide-in menu, `prefers-reduced-motion` support, content visible with JavaScript off

## Files
- `index.html` structure and content
- `style.css` design tokens, layout and animations
- `script.js` interactions

## Run locally
Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```
